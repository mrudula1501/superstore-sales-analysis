# Superstore Sales Analysis

## Project Overview
End-to-end sales analysis of 9,800 orders from a US retail superstore (2015–2018).

## Tools Used
- **Google Sheets** — Data cleaning, pivot tables, charts
- **SQL (SQLite)** — Aggregation queries
- **Python** — pandas, matplotlib, seaborn for analysis and visualization
- **Tableau** — Interactive dashboard

## Key Findings
- West region leads in sales (~$725K)
- Technology is the top category ($827K)
- Sales grew from $479K (2015) to $722K (2018)
- Sean Miller is the top customer (~$25K)
